# Fleeting GitHub Pages

This folder contains the static GitHub Pages site for Fleeting.

## Files

- `index.html`: Fleeting landing page
- `privacy.html`: App Store Privacy Policy URL
- `support.html`: App Store Support URL
- `styles.css`: Shared styling
- `assets/icon.png`: App icon used by the landing page

## GitHub Pages Setup

1. Push this repository to GitHub.
2. Go to Settings → Pages.
3. Set Source to Deploy from branch.
4. Set Branch to `main`.
5. Set Folder to `/docs`.
6. Save.

For this repository, the expected App Store URLs are:

- `https://fleeting-app.github.io/Privacy-Policy/privacy.html`
- `https://fleeting-app.github.io/Privacy-Policy/support.html`

Template URLs:

- `https://USERNAME.github.io/REPOSITORY_NAME/privacy.html`
- `https://USERNAME.github.io/REPOSITORY_NAME/support.html`
